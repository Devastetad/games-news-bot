# Бот игровых новостей

Круглосуточно собирает новости из 10 игровых RSS-лент (StopGame, Игромания, Канобу,
3DNews, PlayGround, IGN, PC Gamer, Eurogamer, GameSpot, Rock Paper Shotgun)
и присылает новые в Telegram: всем подписчикам и, по желанию, в ваш канал.

Работает бесплатно на GitHub Actions, компьютер может быть выключен.
Бот просыпается примерно раз в 10 минут: собирает новости и отвечает на команды,
пришедшие за это время.

## Установка на GitHub (один раз)

1. Зарегистрируйтесь на [github.com](https://github.com) или войдите.
2. Справа вверху нажмите **+** → **New repository**. Имя: `games-news-bot`,
   тип **Public** (для публичных репозиториев Actions бесплатны без лимита) → **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
   Перетащите в окно из папки бота: `.github`, `bot.py`, `config.py`,
   `requirements.txt`, `state.json`, `.gitignore`, `README.md`.
   **Не загружайте** `.env`, `.venv` и `__pycache__`. Нажмите **Commit changes**.
4. **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
   Name: `BOT_TOKEN`, Secret: токен от @BotFather → **Add secret**.
   Для канала добавьте так же секрет `CHANNEL_ID` (например `@my_channel`, бот должен быть админом канала).
5. Вкладка **Actions** → слева **games-news** → **Run workflow** → **Run workflow**.
   Через минуту должна появиться зелёная галочка. Дальше бот запускается сам.
6. Напишите боту `/start`: он подпишет вас при следующем запуске (в течение ~10 минут).

## Команды

- `/start`: подписаться
- `/latest`: последние 10 новостей
- `/sources`: список источников
- `/stop`: отписаться
- `/id`: узнать chat ID

## Настройка (`config.py`)

Редактируйте `config.py` прямо на GitHub (иконка карандаша), изменения подхватятся при следующем запуске.

- `FEEDS`: источники, можно добавлять свои RSS
- `KEYWORDS`: присылать только новости с этими словами (например `["GTA", "Nintendo"]`)
- `STOP_WORDS`: не присылать новости с этими словами
- `SUMMARY_LEN`: длина описания под заголовком

Частота запуска задаётся в `.github/workflows/news.yml` (строка `cron`).

## Важно

- Не запускайте бота одновременно на компьютере (`start.bat`) и на GitHub:
  обе копии будут перехватывать команды друг у друга.
- `state.json` бот обновляет сам, это его память (что уже отправлено, кто подписан).
- Если в репозитории 60 дней не будет изменений, GitHub приостановит расписание.
  Бот сам сохраняет `state.json` после каждой новости, так что при обычной работе этого не случится.
- Запуск на своём ПК (для проверки): впишите токен в `.env` и запустите `start.bat`.
